# f855.第 3 題 線段覆蓋長度 測資加強版

## 題目解釋

可以，這題的核心其實只有一句話：

> **很多條線段可能重疊，問它們合起來到底覆蓋多長。**

範例有 5 條線段：

```text
160 180
150 200
280 300
300 330
190 210
```

把它們畫在數線上：

```text
150       180       210              280       300       330
|----------|----------|                |---------|---------|

150 ---------------- 200
     160 ----- 180
               190 ----- 210

                                      280 ----- 300
                                                300 ----- 330
```

你會發現前面三條其實黏在一起：

```text
150 ~ 200
160 ~ 180
190 ~ 210

合起來就是：

150 ---------------------- 210
```

長度：

\[
210-150=60
\]

後面兩條：

```text
280 ~ 300
300 ~ 330
```

剛好接起來：

```text
280 ---------------- 330
```

長度：

\[
330-280=50
\]

所以答案：

\[
60+50=110
\]

## 解題方向

1. 先排序：我們先按照「起點」從小排到大：

```text
150 200
160 180
190 210
280 300
300 330
```

這樣事情突然就簡單很多。因為我們只需要**從左往右，一條一條看。**

2. 準備一個目前正在處理的範圍

```text
排序後第一條：
150 ~ 200

我們先記住：
left = 150;
right = 200;
```

### 下一條：160 ~ 180

目前：

```text
150 ---------------- 200
```

新來：

```text
    160 -------- 180
```

它完全躲在裡面。

所以目前覆蓋範圍根本不用改：

```text
150 ---------------- 200
```

怎麼知道它們重疊？看新線段的起點：

```text
160 <= 200
也就是新線段的 left <= 目前的 right，代表它碰得到目前的線段。
```

### 下一條：190 ~ 210

目前：

```text
150 ---------------- 200
```

新來：

```text
               190 -------- 210
```

兩條有重疊。

因為：

```text
190 <= 200
```

所以要把右邊延長：

```text
150 ---------------------- 210
```

原本：

```cpp
right = 200;
```

現在：

```cpp
right = 210;
```

可以寫：

```cpp
right = max(right, 新線段右端);
```

也就是：

```cpp
right = max(200, 210);
```

得到：

```text
210
```

---

### 下一條：280 ~ 300

目前：

```text
150 ---------------------- 210
```

新線段：

```text
                              280 -------- 300
```

這次完全碰不到。

因為：

```text
280 > 210
```

所以我們知道：

> `150 ~ 210` 已經結束了，以後不可能再有線段接到它。

為什麼可以這麼確定？因為我們**已經排序過**。後面的線段只會更右邊。

因此可以正式把這一段算進答案：

\[
210-150=60
\]

程式：

```cpp
answer += right - left;
```

得到：

```text
answer = 60
```

接著把：

```text
280 ~ 300
```

當成新的範圍：

```cpp
left = 280;
right = 300;
```

### 下一條：300 ~ 330

目前：

```text
280 -------- 300
```

新線段：

```text
             300 -------- 330
```

注意：

```text
300 <= 300
```

所以它們是連在一起的。

更新：

```cpp
right = max(300, 330);
```

得到：

```text
right = 330
```

現在：

```text
280 ---------------- 330
```

### 全部跑完，最後一條清算

```text
280 ~ 330
```

還沒算。

所以迴圈結束之後一定要：

```cpp
answer += right - left;
```

也就是：

\[
60+(330-280)
\]

\[
=60+50
\]

\[
=\boxed{110}
\]

### C++ 要怎麼存線段？

一條線段有兩個數字：

```text
起點 終點
```

例如：

```text
150 200
```

```cpp

pair<int, int> line;

line.first //就是第一個數字。
line.second 就是第二個數字。
```

### 多條線段就用 vector

```cpp
vector<pair<int, int>> lines;
```

你可以把它想成：

```text
lines

[0] → {160, 180}
[1] → {150, 200}
[2] → {280, 300}
[3] → {300, 330}
[4] → {190, 210}
```

### AC 版本

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;


int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<pair<int, int>> lines;

    // 讀取 n 條線段
    for (int i = 0; i < n; i++) {
        int left, right;
        cin >> left >> right;

        lines.push_back({left, right});
    }

    // 按照線段起點由小到大排序
    sort(lines.begin(), lines.end());

    // 先拿第一條線段當作目前範圍
    int currentLeft = lines[0].first;
    int currentRight = lines[0].second;

    int answer = 0;

    // 從第二條線段開始檢查
    for (int i = 1; i < n; i++) {
        int newLeft = lines[i].first;
        int newRight = lines[i].second;

        // 有重疊或剛好連在一起
        if (newLeft <= currentRight) {
            currentRight = max(currentRight, newRight);
        }

        // 沒有重疊
        else {
            answer += currentRight - currentLeft;

            // 開始新的覆蓋範圍
            currentLeft = newLeft;
            currentRight = newRight;
        }
    }

    // 最後一段還沒有加入答案
    answer += currentRight - currentLeft;
    cout << answer << '\n';
    return 0;
}
```

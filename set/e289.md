# e289.美麗的彩帶

## 題目理解

連續拿出 `m` 個顏色，如果這 `m` 個全部不重複，就算「漂亮」一次。最後有幾次？

輸入：

```text
3 7
1 2 3 5 4 5 4
```

其中：

```text
m = 3  → 每次要看連續 3 個顏色
n = 7  → 彩帶總共有 7 個顏色
```

彩帶：

```text
1 2 3 5 4 5 4
```

因為 `m = 3`，所以拿尺框住連續 3 個：

```text
[1 2 3] 5 4 5 4
```

然後尺往右移一格：

```text
1 [2 3 5] 4 5 4
```

再移：

```text
1 2 [3 5 4] 5 4
```

再移：

```text
1 2 3 [5 4 5] 4
```

再移：

```text
1 2 3 5 [4 5 4]
```

總共有：

\[
7-3+1=5
\]

個長度為 3 的區間。

### 哪些算漂亮？

規則是：「長度 `m` 的區間裡，要剛好有 `m` 種顏色。」

逐個檢查：

```text
1 2 3 → 3 種顏色 ✓ → 漂亮
2 3 5 → 3 種顏色 ✓ → 漂亮
3 5 4 → 3 種顏色 ✓ → 漂亮
5 4 5 → 只有 5、4 兩種 ✗ → 不漂亮
4 5 4 → 只有 4、5 兩種 ✗ → 不漂亮
```

答案：

```text
3
```

## 解法1：vector + set + 兩層 for(很容易理解題目)

> 這個寫法，在最後一個側資會TLE

最直覺的解法：可以把每一組 `m` 個數字拿出來，看看有沒有重複。

例如：

```text
1 2 3
```

我們可以用 C++ 的 `set`。

`set` 有一個很方便的特性：**同一個東西只能放一次。**

例如：

```cpp
set<string> colors;

colors.insert("1");
colors.insert("2");
colors.insert("3");
// 裡面有1 2 3
// 所以colors.size()得到3
```

但如果：

```cpp
colors.insert("5");
colors.insert("4");
colors.insert("5");
// 裡面有4 5
// 所以colors.size()得到2
```

### 完整寫法

```cpp
#include <iostream>
#include <vector>
#include <set>
#include <string>
using namespace std;


int main() {
    // C++ 輸入輸出加速
    ios::sync_with_stdio(0);
    cin.tie(0);

    int m, n;
    cin >> m >> n;

    vector<string> colors(n);

    // 讀取彩帶的顏色
    for (int i = 0; i < n; i++) {
        cin >> colors[i];
    }

    int answer = 0;

    // 每次取出連續 m 個顏色
    for (int i = 0; i <= n - m; i++) {
        set<string> differentColors;

        // 將這 m 個顏色放進 set
        for (int j = i; j < i + m; j++) {
            differentColors.insert(colors[j]);
        }

        // 如果有 m 種不同顏色，代表沒有任何重複
        if (differentColors.size() == m) {
            answer++;
        }
    }

    cout << answer << '\n';

    return 0;
}
```

## 解法2：Sliding Window + unordered_map

### 改成 **Sliding Window(滑動視窗)**：

為什麼你原本的程式很慢？這裡有兩層 `for`：

```cpp
for (int i = 0; i <= n - m; i++) {

    set<string> differentColors;

    for (int j = i; j < i + m; j++) {
        differentColors.insert(colors[j]);
    }
}
```

改成 **Sliding Window(滑動視窗)**，這樣會快非常多。

```text
[1 2 3] 5 4 5 4

往右移
1 [2 3 5] 4 5 4

只做兩件事：
1 離開
5 進來
```

### set改成map

我們不要每次重新建立SET，而是準備一個東西，永遠記住「目前這 `m` 個顏色」的狀況。

這裡可以使用：

```cpp
unordered_map<string, int> count;
```

它可以記錄：

```text
顏色 → 出現幾次
```

例如目前視窗：

```text
5 4 5
```

就記成：

```text
"5" → 2 次
"4" → 1 次
```

因此：

```cpp
count.size()
```

就是2

### 完整寫法

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <unordered_map>
using namespace std;


int main() {
    // C++ 輸入輸出加速
    ios::sync_with_stdio(0);
    cin.tie(0);

    int m, n;
    cin >> m >> n;

    vector<string> colors(n);

    // 讀取彩帶的顏色
    for (int i = 0; i < n; i++) {
        cin >> colors[i];
    }

    // 記錄目前視窗中，每個顏色出現幾次
    unordered_map<string, int> count;

    // 先放入前 m 個顏色
    for (int i = 0; i < m; i++) {
        count[colors[i]]++;
    }

    int answer = 0;

    // 檢查第一個視窗
    if (count.size() == m) {
        answer++;
    }

    // 將視窗慢慢往右移
    for (int i = m; i < n; i++) {

        // 左邊的顏色離開
        string oldColor = colors[i - m];
        count[oldColor]--;

        // 如果這個顏色已經完全不存在，就從 map 刪掉
        if (count[oldColor] == 0) {
            count.erase(oldColor);
        }

        // 右邊加入新的顏色
        string newColor = colors[i];
        count[newColor]++;

        // 如果剛好有 m 種不同顏色，代表這一段沒有重複
        if (count.size() == m) {
            answer++;
        }
    }

    cout << answer << '\n';

    return 0;
}
```

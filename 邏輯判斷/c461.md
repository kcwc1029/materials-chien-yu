# c461.apcs 邏輯運算子 (Logic Operators)

## 題目理解

這題其實是在考最基本的 **AND、OR、XOR 邏輯運算**。比較容易搞混的地方是：題目的 `a`、`b` 不一定只有 0 和 1，例如也可能是 `3 0 1`。

輸入有：

```text
a b result
```

例如：

```text
0 0 0
```

意思不是叫你選一個運算。

而是問你：

> `a=0`、`b=0`，哪些邏輯運算的答案會等於 `result=0`？

我們一個一個試。

### AND

```text
0 AND 0
假 AND 假
→ 0
```

跟題目要求的：

```text
result = 0
```

一樣。

所以輸出：

```text
AND
```

### OR

```text
0 OR 0
假 OR 假
→ 0
```

也是 0。

所以：

```text
OR
```

### XOR

```text
0 XOR 0

兩邊一樣
→ 0
```

也是 0。

所以：

```text
XOR
```

最後答案：

```text
AND
OR
XOR
```

## 解題方向

先讀：

```cpp
int a, b, result;
cin >> a >> b >> result;
```

接著把 `a`、`b` 轉成真假：

```cpp
bool A = (a != 0);
bool B = (b != 0);
```

例如：

```text
a = 3
b = 0
```

那：

```text
A = true
B = false
```

### 判斷 AND

```cpp
if ((A && B) == result) {
    cout << "AND\n";
}
```

### 判斷 OR

```cpp
if ((A || B) == result) {
    cout << "OR\n";
}
```

### 判斷 XOR

```cpp
if ((A != B) == result) {
    cout << "XOR\n";
}
```

### 處理 IMPOSSIBLE

例如：

```text
0 0 1
```

試看看：

```text
AND → 0
OR  → 0
XOR → 0
```

沒有任何一個得到 `1`。

所以：

```text
IMPOSSIBLE
```

我們可以準備：

```cpp
bool found = false;
```

只要找到答案：

```cpp
found = true;
```

最後如果還是：

```cpp
found == false
```

代表三個全部失敗。

### 完整 AC 版本

```cpp
#include <iostream>
using namespace std;


int main() {
    int a, b, result;
    cin >> a >> b >> result;

    // 0 代表假，非 0 代表真
    bool A = (a != 0);
    bool B = (b != 0);

    // 記錄有沒有找到符合的運算
    bool found = false;

    // AND：兩個都是真，結果才是真
    if ((A && B) == result) {
        cout << "AND\n";
        found = true;
    }

    // OR：至少一個是真，結果就是真
    if ((A || B) == result) {
        cout << "OR\n";
        found = true;
    }

    // XOR：兩個不同時，結果為真
    if ((A != B) == result) {
        cout << "XOR\n";
        found = true;
    }

    // 三種運算都不符合
    if (found == false) {
        cout << "IMPOSSIBLE\n";
    }

    return 0;
}
```

# e283.APCS 類似題 - 小崴的特殊編碼

## 題目解釋

題目規定 A～F 各自有自己的密碼：

```text
A → 0 1 0 1
B → 0 1 1 1
C → 0 0 1 0
D → 1 1 0 1
E → 1 0 0 0
F → 1 1 0 0
```

現在 ZeroJudge 不會直接告訴你：

```text
A
```

而是給你：

```text
0 1 0 1
```

你要查表後知道：

```text
0 1 0 1 → A
```

### 先看最簡單的例子

假設輸入：

```text
1
0 1 0 1
```

第一個：

```text
1
```

代表：

> 接下來有 1 個字元。

接著看到：

```text
0 1 0 1
```

查表：

```text
0 1 0 1 → A
```

所以輸出：

```text
A
```

## 解法1：判斷式(會TLE)

### 判斷四個數字？

最直覺的方法就是：

```cpp
if (a == 0 && b == 1 && c == 0 && d == 1) {
    cout << "A";
}
else if (a == 0 && b == 1 && c == 1 && d == 1) {
    cout << "B";
}
else if (a == 0 && b == 0 && c == 1 && d == 0) {
    cout << "C";
}
else if (a == 1 && b == 1 && c == 0 && d == 1) {
    cout << "D";
}
else if (a == 1 && b == 0 && c == 0 && d == 0) {
    cout << "E";
}
else if (a == 1 && b == 1 && c == 0 && d == 0) {
    cout << "F";
}
```

### 完整寫法

```cpp
#include <iostream>
using namespace std;

int main() {
    // c++ 加速
    ios::sync_with_stdio(0);
    cin.tie(0);

    unsigned int n;

    // 持續讀取每一組資料，直到 EOF
    while (cin >> n) {

        // 一組資料裡面有 n 個字元
        for (unsigned int i = 0; i < n; i++) {
            int a, b, c, d;

            // 讀取 4 個 0 或 1
            cin >> a >> b >> c >> d;

            // 根據題目的表格進行解碼
            if (a == 0 && b == 1 && c == 0 && d == 1) {
                cout << "A";
            }
            else if (a == 0 && b == 1 && c == 1 && d == 1) {
                cout << "B";
            }
            else if (a == 0 && b == 0 && c == 1 && d == 0) {
                cout << "C";
            }
            else if (a == 1 && b == 1 && c == 0 && d == 1) {
                cout << "D";
            }
            else if (a == 1 && b == 0 && c == 0 && d == 0) {
                cout << "E";
            }
            else if (a == 1 && b == 1 && c == 0 && d == 0) {
                cout << "F";
            }
        }

        // 每組答案輸出完後換行
        cout << endl;
    }

    return 0;
}
```

## 解法2：二進位

例如：

```text
A → 0 1 0 1
```

其實就是二進位：

\[
0101_2
\]

轉成十進位：

\[
0\times8+1\times4+0\times2+1\times1=5
\]

所以：

```text
A → 0101 → 5
```

其他也是：

| 字母 | 二進位 | 十進位 |
| ---- | ------ | -----: |
| A    | 0101   |      5 |
| B    | 0111   |      7 |
| C    | 0010   |      2 |
| D    | 1101   |     13 |
| E    | 1000   |      8 |
| F    | 1100   |     12 |

假設：

```cpp
cin >> a >> b >> c >> d;
```

可以直接算：

```cpp
int number = a * 8 + b * 4 + c * 2 + d;
```

例如：

```text
0 1 0 1

= 0×8 + 1×4 + 0×2 + 1×1
= 5
```

然後只需要：

```cpp
if (number == 5) {
    cout << "A";
}
else if (number == 7) {
    cout << "B";
}
...
```

### 完整寫法

```cpp
#include <iostream>
using namespace std;


int main() {
    // C++ 輸入輸出加速
    ios::sync_with_stdio(0);
    cin.tie(0);

    unsigned int n;

    // 持續讀取每一組資料，直到 EOF
    while (cin >> n) {

        // 每組資料有 n 個字元
        for (unsigned int i = 0; i < n; i++) {
            int a, b, c, d;

            // 讀取 4 個二進位數字
            cin >> a >> b >> c >> d;

            // 將二進位轉成十進位
            int number = a * 8 + b * 4 + c * 2 + d;
            // 根據十進位數字找回原本的字母
            if (number == 5) {
                cout << 'A';
            }
            else if (number == 7) {
                cout << 'B';
            }
            else if (number == 2) {
                cout << 'C';
            }
            else if (number == 13) {
                cout << 'D';
            }
            else if (number == 8) {
                cout << 'E';
            }
            else if (number == 12) {
                cout << 'F';
            }
        }
        // 每組資料解碼完成後換行
        cout << '\n';
    }
    return 0;
}
```

# e286.籃球比賽

## 題目解釋

**把每隊四局分數加起來 → 看主隊兩場總共贏幾場。**

## 先把題目翻成白話

總共有 **2 場籃球比賽**。

每場都有主隊與客隊，而且每隊都有 4 局的分數。所以輸入總共有 4 行：

```text
第 1 行：第一場 主隊
87 87 87 87
第 2 行：第一場 客隊
78 78 78 78

第 3 行：第二場 主隊
87 87 87 87
第 4 行：第二場 客隊
78 78 78 78
```

## 解題方向

1. 算總分

第一場主隊：

\[
87+87+87+87=348
\]

第一場客隊：

\[
78+78+78+78=312
\]

所以第一場要輸出：

```text
348:312
```

## 第二場也做一樣的事情

第二場：

```text
主隊：87 + 87 + 87 + 87 = 348
客隊：78 + 78 + 78 + 78 = 312
```

輸出：

```text
348:312
```

現在主隊：

```text
第一場 348 > 312 → 主隊贏
第二場 348 > 312 → 主隊贏
```

2. 判斷輸贏

主隊兩場都贏，所以：

```text
Win
```

### 完整程式

```cpp
#include <iostream>
using namespace std;


int main() {
    int a, b, c, d;

    int home1;  // 第一場主隊總分
    int guest1; // 第一場客隊總分
    int home2;  // 第二場主隊總分
    int guest2; // 第二場客隊總分

    // 第一場主隊
    cin >> a >> b >> c >> d;
    home1 = a + b + c + d;

    // 第一場客隊
    cin >> a >> b >> c >> d;
    guest1 = a + b + c + d;

    // 第二場主隊
    cin >> a >> b >> c >> d;
    home2 = a + b + c + d;

    // 第二場客隊
    cin >> a >> b >> c >> d;
    guest2 = a + b + c + d;

    // 輸出兩場比數
    cout << home1 << ":" << guest1 << endl;
    cout << home2 << ":" << guest2 << endl;

    // 計算主隊贏了幾場
    int win = 0;

    if (home1 > guest1) {
        win++;
    }

    if (home2 > guest2) {
        win++;
    }

    // 判斷最後結果
    if (win == 2) {
        cout << "Win" << endl;
    }
    else if (win == 1) {
        cout << "Tie" << endl;
    }
    else {
        cout << "Lose" << endl;
    }

    return 0;
}
```

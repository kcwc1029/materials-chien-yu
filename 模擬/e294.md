## 題目解釋

它定義了一種「完全奇數」：一個數字的**每一位都必須是奇數**。奇數數字只有：

```text
1、3、5、7、9
```

所以：

```text
7       → 完全奇數
135     → 完全奇數
97315   → 完全奇數

123     → 不是，因為有 2
105     → 不是，因為有 0
6789    → 不是，因為有 6、8
```

題目會給你一個 `N`，你要找出「離 N 最近的完全奇數 K」，最後輸出\(|K-N|\)，也就是兩個數字差多少。

假設：N = 135，135 每一位都是`1、3、5`，全部都是奇數。所以它自己就是完全奇數：

```text
K = 135
```

因此：

```text
|135 - 135| = 0
```

答案就是：0

---

再看：

```text
N = 1001
```

1001 不是完全奇數，因為裡面有 `0`。那我們就往左右找：

```text
999   ← 完全奇數
1000
1001  ← N
1002
1003
...
```

最近的是：

```text
999
```

距離：\(|999-1001|=2\)，所以答案：2

## 解題方向：左右一起找

假設：

```text
N = 13256
```

我們不知道最近的完全奇數在哪。

那就從距離 `0` 開始：

```text
距離 0：
13256

距離 1：
13255
13257

距離 2：
13254
13258

距離 3：
13253
13259

...
```

也就是每次檢查：

```python
N - distance
N + distance
```

只要其中一個是完全奇數，我們就找到答案了。

因為我們是從：

```text
0
1
2
3
4
5
...
```

慢慢增加距離，所以**第一個找到的一定是最近的**。

### 怎麼判斷「完全奇數」？

1. 把數字轉成字串：

```cpp
bool isAllOdd(long long number) {
    // 把數字轉成字串
    string text = to_string(number);
    // 一個字元一個字元檢查
    for (char digit : text) {
        if (digit != '1' && digit != '3' && digit != '5' &&
            digit != '7' && digit != '9') {
            return false;
        }
    }
    return true;
}
```

### 接著開始往左右找

```cpp
long long n = 1001;
long long distance = 0;

while (true) {
    long long left = n - distance;
    long long right = n + distance;

    if (left > 0 && isAllOdd(left)) {
        cout << distance << endl;
        break;
    }

    if (isAllOdd(right)) {
        cout << distance << endl;
        break;
    }

    distance++;
}
```

### 完整寫法

```cpp
#include <iostream>
#include <string>
using namespace std;


// 判斷是不是完全奇數
bool isAllOdd(long long number) {
    string text = to_string(number); // 將數字轉換成字串

    for (char digit : text) { // 一個位數一個位數檢查
        if ((digit - '0') % 2 == 0) { // 如果這個數字是偶數
            return false;
        }
    }

    return true;
}


int main() {
    // C++ 輸入輸出加速
    ios::sync_with_stdio(0);
    cin.tie(0);
    long long n;

    // 不知道有幾筆輸入，所以持續讀取到 EOF
    while (cin >> n) {
        long long distance = 0;

        // 從 n 的左右兩邊慢慢尋找
        while (true) {
            long long left = n - distance;
            long long right = n + distance;

            // 檢查左邊
            if (left > 0 && isAllOdd(left)) {
                cout << distance << endl;
                break;
            }

            // 檢查右邊
            if (isAllOdd(right)) {
                cout << distance << endl;
                break;
            }

            distance++;
        }
    }

    return 0;
}
```
